## ⚠️ WATCH OUT FOR

### From Money Lover
- **Security concern flagged:** TechRadar reported security flaws (2024). Verify current status before recommending.
- **Smaller feature set.** Don't assume "simpler = better for beginners"; Spendee proved clean design wins.

### From Spendee
- **No recurring expenses setup.** If user has subscriptions, they're stuck with monthly budget alerts.
- **Shared wallets may create conflict.** "Who paid what" transparency can cause arguments if settlement isn't automated.

### From Toshl
- **River Flow is beautiful but maybe too abstract.** Some users find Toshl "overwhelming" (multiple dimensions: period, budget, category, tag, location).
- **No collaboration.** Single-user model is a trap for modern finance (couples, families, businesses all need sharing).

## 🎓 STRATEGIC INSIGHTS

### 1. **Market is Bifurcating**
- **Category 1:** Simple shared wallets for couples/roommates (Spendee)
- **Category 2:** Multi-currency for nomads/expats (Toshl)
- **Category 3:** Southeast Asia localized (Money Lover)
- **MMW's opportunity:** Telegram-first for shared finances (Category 1 + platform differentiation)

### 2. **Feature Maturity Curve**
- **Mature:** Bank sync (all three), budgets (all three), multi-account (all three)
- **Growth:** Collaboration (Spendee only), recurring flexibility (Toshl only), OCR (Spendee only)
- **Emerging:** P/B tagging (none), tax export (none), AI insights (none)
- **MMW should compete on Growth/Emerging,** not Mature (too crowded)

### 3. **Pricing Sweet Spot**
- Free tier critical (all three offer)
- $3-5/mo for pro (Spendee $5.99, Toshl $4.99 = accept standard)
- Lifetime $20-120 for niche users (Money Lover $19.99, Spendee $119.99 = high variance)
- **MMW recommendation:** $0 free + $2.99/mo for premium (undercut Spendee on price)

### 4. **Rating = Marketing**
- Toshl has highest rating (4.7★) but fewest reviews (1.8K) → niche audience
- Spendee highest review count (6.1K) → broader appeal
- Money Lover largest user base (10M) but not newest → network effect or legacy adoption
- **MMW implication:** Quality reviews matter more than user count (build trust early)
